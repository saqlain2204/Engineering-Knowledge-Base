Deep, beginner-friendly guides. Start anywhere: each page defines its own terms and links to related topics.

Suggested reading order

New to these subjects? This order builds each idea on the one before it. Every page also stands on its own.

  1. Processes, Threads & CPU Scheduling: what a running program is
  2. Virtual Memory & Paging: how programs see memory
  3. File Systems & Disk I/O: how data is saved, and when it is really safe
  4. Concurrency, Synchronization & Deadlocks: what goes wrong when threads share data
  5. Normalization & Schema Design: which tables a database should have
  6. Transactions, Isolation Levels & MVCC: the same problems inside a database
  7. Indexing, B+ Trees & Query Plans: how databases find data fast
  8. Replication, Sharding & the CAP Theorem: when one database server is not enough
  9. IP Addressing, Subnetting & Routing: how packets find their way
  10. TCP Deep Dive: how bytes cross the network reliably
  11. DNS & HTTP: from a name to a web page
  12. TLS, HTTPS & Certificates: how strangers talk privately and prove who they are
  13. Scenario: Debugging a Slow API End to End: everything above, used together
  14. Scenario: A Service Cannot Reach Its Database: a network mystery solved layer by layer
  15. Scenario: Errors During Every Deploy: why releases cause 502s, measured and fixed

Operating Systems

  • Processes, Threads & CPU Scheduling - process states, context switches, fork/exec, threads, FCFS/SJF/SRTF/Round Robin worked by hand, Linux EEVDF and sched_ext, container CPU throttling
  • Virtual Memory & Paging - address translation in hex, multi-level page tables, TLBs, page faults, FIFO/LRU/OPT traced step by step, thrashing, huge pages, OOM kills
  • File Systems & Disk I/O - file descriptors, inodes and links, block pointer math, extents, the page cache, write vs fsync and the safe-save pattern, journaling, epoll and io_uring, container overlay layers, debugging full and slow disks

Databases

  • Normalization & Schema Design - update, insert and delete anomalies, keys, functional dependencies, closure and finding keys by hand, 1NF to BCNF and 4NF worked step by step, lossless splits, ER diagrams to tables, when to denormalize, a runnable SQL lab
  • Transactions, Isolation Levels & MVCC - ACID, write-ahead logging, anomalies as timelines, PostgreSQL vs MySQL isolation, MVCC internals, locking and deadlocks, a hands-on lab
  • Indexing, B+ Trees & Query Plans - pages and full scans, B+ trees built by hand with splits, tree height math, hash, clustered and covering indexes, the leftmost-prefix rule, reading real PostgreSQL EXPLAIN output, write cost, LSM trees
  • Replication, Sharding & the CAP Theorem - leaders and followers, sync vs async commits, replication lag and stale reads, failover and split brain, quorums (W + R > N), range and hash sharding, a consistent hashing experiment, hot keys, CAP and PACELC

Computer Networks

  • IP Addressing, Subnetting & Routing - binary, CIDR and masks, network and broadcast by hand, subnetting and VLSM, private ranges, ARP and gateways, longest prefix match, NAT, IPv6, cloud VPC and Kubernetes address planning
  • TCP Deep Dive - handshake with real sequence numbers, retransmission, flow and congestion control (CUBIC, BBR), TIME_WAIT, TLS 1.3 and HTTP/3 latency budgets, debugging recipes
  • DNS & HTTP: From a Name to a Web Page - the DNS tree, a lookup traced step by step, record types with real answers, TTL math, Kubernetes ndots, HTTP messages, idempotency, status codes, cookies, caching with ETag and 304, a zero-downtime DNS move
  • TLS, HTTPS & Certificates - symmetric and public-key crypto, Diffie-Hellman by hand, signatures, the chain of trust, the TLS 1.3 handshake from real openssl output, resumption and 0-RTT, a lab that breaks certificates on purpose, mTLS, TLS at load balancers

Scenarios

  • Debugging a Slow API End to End - percentiles, RED and USE, splitting time with curl, uptime and vmstat, Little's law for connection pools, pg_stat_statements and EXPLAIN, retry storms, load shedding, a blameless postmortem, practice problems
  • A Service Cannot Reach Its Database - what each connection error means, DNS, TCP and firewall checks, ip route get and tcpdump, an overlapping pod range, a proxy workaround, TLS and connection-limit errors, a CIDR overlap check for CI
  • Errors During Every Deploy - 502 vs 503 vs 504, the race between SIGTERM and load balancer updates, a runnable lab measuring four fixes, graceful shutdown, keep-alive timeout races, safe retries and idempotency keys, a deploy check for CI
