Suggested reading order

New to these subjects? This order builds each idea on the one before it. Every page also stands on its own.

  1. Processes, Threads & CPU Scheduling: what a running program is
  2. System Calls & the Kernel Boundary: how a program asks the operating system for help
  3. Virtual Memory & Paging: how programs see memory
  4. Memory Allocation & Garbage Collection: who hands out memory, and who gives it back
  5. CPU Caches & the Memory Hierarchy: why some memory is fast and some is slow
  6. File Systems & Disk I/O: how data is saved, and when it is really safe
  7. I/O Models & Event Loops: why one slow read can stall many clients
  8. Concurrency, Synchronization & Deadlocks: what goes wrong when threads share data
  9. Normalization & Schema Design: which tables a database should have
  10. Transactions, Isolation Levels & MVCC: the same problems inside a database
  11. Indexing, B+ Trees & Query Plans: how databases find data fast
  12. SQL Joins & How the Database Executes Them: how tables are stitched back together, and how the engine does it
  13. SQL Aggregation, GROUP BY & Window Functions: turning many rows into answers
  14. Replication, Sharding & the CAP Theorem: when one database server is not enough
  15. IP Addressing, Subnetting & Routing: how packets find their way
  16. TCP Deep Dive: how bytes cross the network reliably
  17. DNS & HTTP: from a name to a web page
  18. TLS, HTTPS & Certificates: how strangers talk privately and prove who they are
  19. QUIC and HTTP/3: a new transport over UDP, and why a lost packet should not stall every stream
  20. Load Balancing & Reverse Proxies: how traffic is spread, and why one slow server can ruin p99
  21. Scenario: Debugging a Slow API End to End: everything above, used together
  22. Scenario: A Service Cannot Reach Its Database: a network mystery solved layer by layer
  23. Scenario: Requests Stuck on Database Locks: a lock queue, an idle transaction, and a frozen migration
  24. Scenario: Errors During Every Deploy: why releases cause 502s, measured and fixed
  25. Scenario: A Pod Keeps Getting OOMKilled: a memory leak found and fixed, from the kill to the cause
  26. Scenario: A Retry Storm Takes the Service Down: a dependency slows, clients retry, and load shedding is the fix
  27. Scenario: The Disk Is Full: deleted files that still use space, inodes, logs, and WAL

Operating Systems

  • Processes, Threads & CPU Scheduling - process states, context switches, fork/exec, threads, FCFS/SJF/SRTF/Round Robin worked by hand, Linux EEVDF and sched_ext, container CPU throttling
  • System Calls & the Kernel Boundary - user space vs kernel space, the trap, syscall families, a lab (getpid at 66 ns vs a 0.28 ns add; writing 1 MB one byte at a time took 260 ms, one write took 0.44 ms), the vDSO, strace, N+1 I/O, seccomp
  • I/O Models & Event Loops - blocking vs non-blocking, thread per client vs event loop, select, poll and epoll, level vs edge triggering, an event loop by hand, async/await, a lab with 200 clients (20 s vs 0.16 s), blocking the loop by mistake, backpressure
  • Virtual Memory & Paging - address translation in hex, multi-level page tables, TLBs, page faults, FIFO/LRU/OPT traced step by step, thrashing, huge pages, OOM kills
  • Memory Allocation & Garbage Collection - stack frames traced by hand, malloc chunks and free lists, fragmentation (freeing half the data gave back 0 KB), memory bugs, reference counting, mark and sweep by hand, generational GC, a GC pause lab, heap settings for containers
  • CPU Caches & the Memory Hierarchy - latency numbers measured by pointer chasing, 64-byte cache lines, tag, set and offset by hand, set-associative caches, the three kinds of misses, AMAT, write-back, a 10x loop-order speedup, MESI coherence, a 5x false-sharing slowdown and its fix, NUMA
  • File Systems & Disk I/O - file descriptors, inodes and links, block pointer math, extents, the page cache, write vs fsync and the safe-save pattern, journaling, epoll and io_uring, container overlay layers, debugging full and slow disks
  • Concurrency, Synchronization & Deadlocks - race conditions, mutexes, semaphores, condition variables, producer-consumer, deadlock conditions, Banker's algorithm, priority inversion

Databases

  • Normalization & Schema Design - update, insert and delete anomalies, keys, functional dependencies, closure and finding keys by hand, 1NF to BCNF and 4NF worked step by step, lossless splits, ER diagrams to tables, when to denormalize, a runnable SQL lab
  • Transactions, Isolation Levels & MVCC - ACID, write-ahead logging, anomalies as timelines, PostgreSQL vs MySQL isolation, MVCC internals, locking and deadlocks, a hands-on lab
  • Indexing, B+ Trees & Query Plans - pages and full scans, B+ trees built by hand with splits, tree height math, hash, clustered and covering indexes, the leftmost-prefix rule, reading real PostgreSQL EXPLAIN output, write cost, LSM trees
  • SQL Joins & How the Database Executes Them - inner, left, right and full joins by hand, cross-join blow-ups, nested loop, hash and merge joins, a lab (301 ms vs 0.79 ms for the same 2,000 by 10,000 join; an index made one-customer lookups 380 times faster), reading EXPLAIN, NULL keys, anti-joins
  • SQL Aggregation, GROUP BY & Window Functions - NULL rules for COUNT, SUM and AVG, GROUP BY as buckets, WHERE vs HAVING and query order, ROW_NUMBER vs RANK vs DENSE_RANK, running totals, LAG, the ROWS vs RANGE trap, top-N per group, hash vs sort aggregation, a lab (77 s correlated subquery vs 34 ms window function)
  • Replication, Sharding & the CAP Theorem - leaders and followers, sync vs async commits, replication lag and stale reads, failover and split brain, quorums (W + R > N), range and hash sharding, a consistent hashing experiment, hot keys, CAP and PACELC

Computer Networks

  • IP Addressing, Subnetting & Routing - binary, CIDR and masks, network and broadcast by hand, subnetting and VLSM, private ranges, ARP and gateways, longest prefix match, NAT, IPv6, cloud VPC and Kubernetes address planning
  • TCP Deep Dive - handshake with real sequence numbers, retransmission, flow and congestion control (CUBIC, BBR), TIME_WAIT, TLS 1.3 and HTTP/3 latency budgets, debugging recipes
  • DNS & HTTP: From a Name to a Web Page - the DNS tree, a lookup traced step by step, record types with real answers, TTL math, Kubernetes ndots, HTTP messages, idempotency, status codes, cookies, caching with ETag and 304, a zero-downtime DNS move
  • TLS, HTTPS & Certificates - symmetric and public-key crypto, Diffie-Hellman by hand, signatures, the chain of trust, the TLS 1.3 handshake from real openssl output, resumption and 0-RTT, a lab that breaks certificates on purpose, mTLS, TLS at load balancers
  • QUIC and HTTP/3 - TCP head-of-line blocking, QUIC streams over UDP, 1-RTT and 0-RTT handshakes (240 ms vs 160 ms vs 80 ms at an 80 ms RTT), connection IDs, a loss lab where one stream finished in 60 ms on QUIC while HTTP/2 held every stream until 209 ms, Alt-Svc and fallback
  • Load Balancing & Reverse Proxies - forward vs reverse proxies, Layer 4 vs Layer 7, round robin, least connections and power of two choices compared in a simulation, the one-slow-server math, health checks, timeouts and safe retries, sticky sessions, X-Forwarded-For, nginx explained, the gRPC one-pod problem, GeoDNS and anycast

Scenarios

  • Debugging a Slow API End to End - percentiles, RED and USE, splitting time with curl, uptime and vmstat, Little's law for connection pools, pg_stat_statements and EXPLAIN, retry storms, load shedding, a blameless postmortem, practice problems
  • A Service Cannot Reach Its Database - what each connection error means, DNS, TCP and firewall checks, ip route get and tcpdump, an overlapping pod range, a proxy workaround, TLS and connection-limit errors, a CIDR overlap check for CI
  • Requests Stuck on Database Locks - lock queues, finding the root blocker with pg_blocking_pids, idle-in-transaction sessions, a migration that froze every read, deadlock logs, a PostgreSQL lab measuring each fix, lock ordering, safe retries, MySQL equivalents, alerts
  • Errors During Every Deploy - 502 vs 503 vs 504, the race between SIGTERM and load balancer updates, a runnable lab measuring four fixes, graceful shutdown, keep-alive timeout races, safe retries and idempotency keys, a deploy check for CI
  • A Pod Keeps Getting OOMKilled - OOMKilled vs evicted vs grace-period kills, RSS, working set, anon and page cache, requests, limits and oom_score_adj, leak-rate math, a real OOM kill under a cgroup limit, tracemalloc, JVM, Go and Node heap settings, right-sizing, alerts
  • A Retry Storm Takes the Service Down - retry amplification math, abandoned work, a lab where a tight queue cap lifted success from 24.5% to 87.8%, 8,805 immediate retries that did not help, a sloppy cap plus retries that dropped success from 55.5% to 35.6%, jitter vs a thundering herd, retry budgets and idempotency
  • The Disk Is Full - the first five minutes, a lab where deleting a 64 MB log freed nothing until the process let go, inode exhaustion with 57 MB free, reserved blocks and hidden mounts, log rotation, journald, Docker and Kubernetes disk eviction, a PostgreSQL slot holding WAL, time-to-full alerts
