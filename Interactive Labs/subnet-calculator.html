Subnet Calculator, Bit by Bit

An IPv4 address is 32 bits. The prefix length says how many of them name the network. The rest name a host. Change the address or the prefix and watch the bits move.

The bits

Network bits are colored. Host bits are plain. The network address keeps the network bits and sets every host bit to 0. The broadcast address sets every host bit to 1.

Subnets

#NetworkUsable hostsBroadcast

How it works

  • The mask has 1s for network bits and 0s for host bits. A /24 mask is 255.255.255.0.
  • Network address = address AND mask. Broadcast = network OR (NOT mask).
  • Usable hosts = 2host bits − 2, because the network and broadcast addresses are reserved. A /31 is a special case (RFC 3021): both addresses are usable on a point-to-point link. A /32 is one single host.
  • Cloud providers reserve more. AWS keeps 5 addresses in every VPC subnet, so a /24 gives 251 usable addresses there, not 254.

Things to try

  • Move the prefix from /24 to /25. Half the hosts disappear, and one more bit turns colored.
  • Load "Cloud /20" and split it into /24s. You get 16 subnets of 254 hosts each.
  • Load "Link /30". Only 2 usable hosts: perfect for a router-to-router link.
