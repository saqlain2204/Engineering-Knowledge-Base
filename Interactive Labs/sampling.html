How an LLM Picks the Next Token

The model gives a score to every possible next token. Sampling settings decide which tokens stay in the race and how likely each one is. Move the sliders and see it live.

How it works

  1. The model outputs a logit (a raw score) for every token in its vocabulary, often 100,000 or more. This lab shows the top 12.
  2. Temperature divides every logit by T before softmax. T below 1 sharpens the distribution. T above 1 flattens it. T = 0 is treated as greedy decoding.
  3. Top-k keeps the k highest tokens. Top-p (nucleus sampling) keeps the smallest top group whose probabilities add up to at least p. Min-p keeps tokens whose probability is at least min-p times the top token's probability, so it adapts to how confident the model is.
  4. The kept tokens are renormalized so they sum to 1, and one is drawn at random.

This lab applies the filters in the order many serving engines use: temperature, then top-k, then top-p, then min-p. Libraries differ a little in the order, so check your engine's docs if exact numbers matter.

Things to try

  • Pick "My favorite color is" and set top-p to 0.5. Few tokens survive. Now pick "The capital of France is". Only one survives. Top-p adapts to the model's confidence.
  • Set temperature to 1.8. Weird tokens get real probability. Now add min-p 0.1. Most of the junk is gone, but the good choices stay.
  • Set temperature to 0 and sample many times. The same token wins every time.
