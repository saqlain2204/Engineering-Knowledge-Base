How it works

  1. Each token has an embedding vector x. The model multiplies it by three learned matrices to get a query q = x·WQ, a key k = x·WK and a value v = x·WV.
  2. The query of one token is compared with the key of every token using a dot product. A big dot product means "this key matches what I am looking for".
  3. Scores are divided by √dk. Without this, scores grow with the head size, softmax becomes almost one-hot, and training gets unstable.
  4. In a decoder (GPT style), the causal mask sets future positions to minus infinity, so their weight becomes exactly 0.
  5. Softmax turns scores into weights that are positive and sum to 1. The output is the weighted sum of the value vectors.

The numbers here are small random toy vectors, so the pattern is not what a trained model would learn. The math is exactly the same. Real models run many heads in parallel (for example 32 or more) and stack dozens of layers.

Things to try

  • Set dk to 8 and untick scaling. Watch the weights collapse onto one token.
  • Turn on the causal mask. The first token can only look at itself, so its weight on itself is 1.
  • Use a sentence with a repeated word, like "the". Both copies get the same key, so they get the same score. Only position information (not shown here) can tell them apart.
