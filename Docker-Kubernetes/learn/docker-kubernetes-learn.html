Docker & Kubernetes Learn

Concepts, diagrams, and hands-on examples from container basics to production-grade Kubernetes.

Suggested reading order

New to containers? This order builds each idea on the one before it. Every page also stands on its own, and each one has Previous / Next links at the bottom.

  1. Docker Fundamentals: what a container and an image are
  2. How Containers Really Work: namespaces, cgroups and images, built by hand
  3. Docker Compose: running several containers together
  4. Advanced Docker: smaller, safer, faster builds
  5. Kubernetes Architecture: the parts of a cluster and how they talk
  6. Workloads: Pods, Deployments, StatefulSets, Jobs
  7. Scheduling: which node each pod lands on, and why
  8. Autoscaling, Probes & Rollouts: staying healthy while traffic and code change
  9. Networking & Services: how traffic reaches pods
  10. Storage: data that outlives a pod
  11. Config, Secrets & Security: settings, secrets, and who may do what
  12. Helm & Observability: packaging apps and watching them run
  13. Debugging Pods: Pending, CrashLoopBackOff, ImagePullBackOff and the rest
  14. Operators & Custom Resources: teaching Kubernetes to run new kinds of things
  15. GPU Scheduling: sharing GPUs and serving LLMs
  16. CI/CD and MLOps on Kubernetes: shipping code and models automatically
  17. Infrastructure as Code: desired state, plans, and why console clicks drift
  18. Experiment Tracking, Model Registry & Feature Stores: which model runs, and why it acts differently live
